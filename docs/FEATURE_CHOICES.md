# 漫匣 · 功能选择清单

日期：2026-10-20。用户已选择全部 42 项。以下保留最初范围与当时状态；实际实现进度见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

当前版本是一版基础界面和在线阅读流程。物理书绘制使用固定投影、渐变和预设模糊阴影，不是完整 3D 材质系统。现有抽书/展开是位置、尺寸与封面宽度插值，详情转场使用 Hero 和淡入；距离参考项目的连续跟手、惯性和玻璃效果仍有差距。

当前发现页只有动漫屋列表、关键词搜索和快捷关键词。没有每日推荐、独立排行榜、分类筛选或个性化推荐。

状态：**加强** = 有基础版本，需要重做/扩展；**新增** = 当前未实现。推荐优先项标记 ★。
