## 继续完善的边界

- Android 真机上的折射、倾斜、触感、音量键、旋转、常亮、功耗和帧率。
- 实际 WebDAV 服务的账号/权限/ETag 兼容，离线图片采用手动触发的 WebDAV ZIP 快照上传/恢复；不自动在后台上传。
- 正式签名 APK 的首次安装、同签名升级和数据保留；CI 调试包不作为正式升级渠道。
- 完整动态文案翻译、整排书的细节编排和 CBR 扩展可以继续推进，不能标为全部完成。
