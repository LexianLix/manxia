## 本地回归与真实内容

- 修改前回归已失败：详情没有原始封面，空目录被当作成功、无法重试；章节容器仅ID或同站完整网址被漏读；缩略图目录混入日期并反转顺序。
- 本地77项Flutter测试、8项Node测试、3项Python测试通过；静态分析无问题。新增覆盖失败重试后阅读按钮恢复、离场重试按钮不可重复提交、共享封面中途返回、3D封面到达与画面缓存、减少动效，以及自定义导航书架落点。
- Release Web构建与离线外壳生成通过；原生构建和设备验证另列，不用Web结果代替。
- 抓取实际动漫屋首页76部漫画详情（使用与App相同手机请求头）：74部解析到自身目录；《英雄再临》明确迁移至漫画人App，《古见同学有交流障碍症》只有外部搜索入口。另取《火影忍者》直连手机页和公开桌面页，两者均解析553章。共78项实际响应回放断言通过，包含两种明确不可读取状态。
- 目录结构未识别时才回退同一作品的公开桌面页；不对明确迁移/停止网页阅读提示、网页验证或HTTP拒绝静默尝试其他入口。预览代理限制目标主机和详情路径，并分开缓存两种版本。
- 目录诊断只保留最近12部的路径、页面字符数、标题、解析分组/章节数、尝试版本和错误；不保存网页正文、Cookie或个人书库。
- 未在用户iQOO上取得同一失败响应。不能从此处553章的成功推断其手机网络已修复，也不能承诺所有作品都能直接阅读。
