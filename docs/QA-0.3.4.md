# v0.3.4 验证记录

版本0.3.4+13。目标是版权提示明确、开书与下滑/翻页连续，并纳入上批已推送的目录和阅读交接。发行状态以本文件末尾的原生及发布检查点为准。

## 行为和复现证据

- 版权：仅在原站明确的版权移除/无授权提示下分类为copyright，按钮与目录直接说明当前书源没有版权。原站完整提示保存在诊断中；有离线章节时仍显示原因并可阅读已下载内容。一般下架、维护、授权声明、外部搜索、超时、页面未识别和App迁移不据此认定为无版权。
- 同样识别缺少标题的明确移除页，以及从旧阅读记录进入章节后的版权移除；保留原站提供的作品封面和元数据，不返回虚构目录。
- 开书：原立体轨迹300ms开度0.7188，到540ms反而降为0.5997，回归确实失败。现从书脊持续向外展开，以同一进度驱动书架/网格移动、展平、封面裁切和落地；开度不再回落。中断返回保留现有Hero及逆向路径，系统和应用减少动效仍直接呈现。
- 封面首帧：原已显示图片重新挂载进入飞行时先出现FutureBuilder等待，回归确实失败。现在复用已有32MB/50项的离线内存缓存和Flutter图片缓存，不增加独立图片缓存；平面封面和3D书体第一帧均有已解码图片。冷加载继续使用有限到达和占位。
- 翻页：原连点三次下一页不到目标页，回归确实失败。现保留未完成的翻页目标，快速重复及改向从当前页位置接续；动态开启减少动效直接到达目标，条漫减少动效跳页不再运行220ms动画。
- 纸张：原进入与离开两页同时弯曲，进一步露出透明间隙；回归取得间隙像素alpha0。现在只弯曲较前的一张纸，补齐纸背后同位置alpha255，正反向共用同一几何，右向左卷曲方向相应反转。删除重复曲线裁剪、旋转和整页阴影，保留图像网格与纸背。
- 缩放手势：初版测试单指移动正好等于触摸阈值，产生错误诊断，现已校正。最终回归检验单指拖动、取消、快速改向、双指缩放、放大后拖图保持页码、通过按钮翻页时复原缩放。不能把早期阈值问题写成已确认的产品手势故障。
- 下滑：统一边界回弹的弹簧与运动节奏；新的手势在当前惯性/回弹位置接手，不排队延迟滚轮输入。减少动效采用边界夹紧；新增漫画按有限时钟显现，已有条目不重新创建，去重后才参与到达。
- 上批目录分组/排序、跨章首屏解码交接及进度保护见 [目录阅读QA](QA-MOTION-READER.md)，纳入本候选。该批源码b25a842的远端CI40077272547已成功完成，包括Android Profile编译；此结果不等于新候选Release启动通过。
