## 目标

1. 书架→翻开封面和书页→详情→反向合书归位，保留中断与回退连续性。
2. 导航的水滴拉伸、桥接、融合和吸附回弹；统一手势、页面及工具栏节奏。
3. 封面满幅融入书体，统一书脊、透视、光影与材质。
4. 更多实用入口及设置：下载、插件、导航定制、阅读与外观选项。
5. 可安装、启停、更新、配置和卸载的插件商城；公开版本化接口、文档、样例和制作工具。
6. README 回归产品介绍、版权、协议和致谢；版本名称简洁，更新说明只写实际修复、改进、删除。

## 接续机制

额度临近上限时生成根目录 `WORK_START.md`，包含确切提交、工作区状态、已验证结果、未完成事项及下一条命令。下一次代理按 `AGENTS.md` 执行 `tools/Resume-Work.ps1`，成功输出后自动删除一次性文档。本计划长期保留；启动文档不会由漫画应用启动时删除。
