# 漫匣交互与插件计划

用户于 2026-10-22 确认开始。按实际实现和验证更新下列状态。

## 目标

1. 书架→翻开封面和书页→详情→反向合书归位，保留中断与回退连续性。
2. 导航的水滴拉伸、桥接、融合和吸附回弹；统一手势、页面及工具栏节奏。
3. 封面满幅融入书体，统一书脊、透视、光影与材质。
4. 更多实用入口及设置：下载、插件、导航定制、阅读与外观选项。
5. 可安装、启停、更新、配置和卸载的插件商城；公开版本化接口、文档、样例和制作工具。
6. README 回归产品介绍、版权、协议和致谢；版本名称简洁，更新说明只写实际修复、改进、删除。

## 当前状态

- 基线：v0.2.4，Android Release 的 JNI 初始化白屏已修复；41 项 Flutter 测试。
- 原生边界：API 30 OpenGLES 模拟器顶部区域绘制有缺失；ARM64 转译器 SIGILL 未计入通过，不能声称 iQOO 真机已验证。
- 已实现：沿书脊开合封面和交错书页、满幅封面与书脊取色、水滴双弹簧连接、跟手页面拖动及系统取消回位。
- 已实现：默认五个入口、导航增减排序、启动页、疏密、亮屏、默认双页 / 背景、工具栏自动收起。
- 已实现：插件 API 1、五个真实内置包、商城启停 / 配置 / 更新 / 卸载、本地 JSON 与 HTTPS 仓库、SHA-256 校验、开发文档 / Schema / SDK。API 1 为声明式扩展，不执行第三方脚本或替换渲染器。

## 接续机制

额度临近上限时生成根目录 `WORK_START.md`，包含确切提交、工作区状态、已验证结果、未完成事项及下一条命令。下一次代理按 `AGENTS.md` 执行 `tools/Resume-Work.ps1`，成功输出后自动删除一次性文档。本计划长期保留；启动文档不会由漫画应用启动时删除。
