# 漫匣使用指南

## 先看效果

在项目目录运行 `启动预览.ps1`，打开 http://127.0.0.1:4173。源码更新后用 `启动预览.ps1 -Rebuild` 重新编译。只复制文档代码框内的命令，不复制反引号。

- 手机：底部书架、发现、足迹、设置；桌面：左侧导航。
- 拖动书脊浏览，放手吸附；点中间书或“翻开这本漫画”打开详情。右上切换封面网格。无个人收藏时显示示例书架。
- 发现页有每日推荐、原站榜单、更新、分类、书单。输入名称或作者，按回车搜索。推荐保存在当前日期/来源/换组的组合下，刷新不会突然换一本。
- 分类从动漫屋读取题材，选择排序和连载状态后点“加载更多”。错误时显示原因或已有缓存，不伪造结果。

## 收藏和整理

详情页点击收藏。书架标题旁的整理按钮可搜索、拖动、排序、批量选中和移组/移除。每本漫画可设置分组、标签、阅读状态和系列名。相同系列可切到套装视图；分组也作为发现页中的个人主题书单。

发现 → 更新 → 检查按钮会分批检查收藏。首次建立基线，以后的新章节会保留提示，打开详情后清除提示。来源超时会报告失败数量。

## 阅读

详情页选择章节，或从足迹继续。阅读器上方打开章节/书签面板和设置。

- 分页、纵向分页、连续长条三种模式；宽屏下可开启双页，封面独立显示。
- 左右分区点击翻页，中间显示控制栏；键盘方向键翻页，空格切换控制栏，Esc 返回。
- 连续模式保存具体图片与图片内位置，可设置自动滚动。长按图片查看大图；分页可双指缩放。
- 阅读设置按漫画保存：方向、纸页效果、裁边、亮度、暖色、背景等。Android 接有音量键翻页与常亮接口；需在设备上确认实际效果。
- 书签按钮可写备注，也可收藏这一页。足迹页切换“书签与笔记”，可筛选页面收藏、搜索和删除。

## 本地漫画和下载

右上下载图标打开管理页，菜单选择 ZIP/CBZ/PDF、多选图片，原生端还可选图片文件夹。图片按自然数字顺序排序（1、2、10），ZIP 内目录不会写入任意系统路径。PDF 逐页转为本地图片；未接入 CBR。

详情选择下载章节后加入队列。暂停会在当前图片结束后停止，继续/重试保留完成页。默认两章并发，可在设置改为一至四章。完成后优先从本机读取，封面尽量一起缓存。单张图超过 20 MB、单个压缩包/PDF 超过 256 MB 会拒绝导入或下载。

管理页显示离线容量，章节可删除或导出 CBZ。设置中的临时缓存清理用于内存解码图和浏览器预览服务的网络图片。离线漫画用管理页清理。

## 备份和恢复

设置 → 备份与同步：

1. JSON 资料备份：收藏、阅读进度、分组、书签、笔记和来源配置，不含正文图片或 WebDAV 密码。
2. 完整离线书库 ZIP：包含完成下载/导入的图片、资料和 SHA-256 校验清单，上限 512 MB。可自行放到网盘。更大的书库按章节导出 CBZ。
3. 恢复时先校验图片。资料以路径去重，保留较新阅读记录；删除标记避免旧备份重新带回已删收藏和书签。

## WebDAV

先在自己的服务端创建专用目录，填写完整 JSON 文件地址，例如 `https://dav.example.com/Manxia/library.json`。首次文件不存在时条件创建；已有文件用强 ETag 合并后条件上传，冲突会要求再同步。服务不支持强 ETag 时拒绝覆盖。

同步收藏、阅读位置、分组、笔记和书签。可选“上传离线书库到 WebDAV”或“从 WebDAV 恢复离线书库”，在同目录的 .offline.zip 中传输图片快照。上传也使用 ETag 条件写入，恢复先校验再合并；其他设备有独有章节时先恢复，再上传合并后的快照。不在后台自动上传漫画。原生端密码进入系统安全存储，浏览器仅保留在当前会话。未配置实际账号时无法证明真实网盘兼容性。

## 自定义源

设置添加 JSON 配置，指定 HTTPS 站点和 CSS 选择器。支持静态 HTML 的首页、搜索、详情章节和图片链接，不执行远程脚本。配置例子和字段解释见 `docs/SOURCES.md`。默认动漫屋适配器另有图片列表解码。

## 外观和语言

设置有夜间模式、动画、指针/设备倾斜、材质档位、封面取色、预载、触感、大字号、高对比度及中英/繁体主要界面翻译。网站漫画名、介绍和部分动态提示保留原文。设备倾斜和玻璃折射依赖硬件/渲染器，不以浏览器预览代替真机验收。
