# 漫匣使用指南

## 先看效果

在项目目录运行 `启动预览.ps1`，打开 http://127.0.0.1:4173。源码更新后用 `启动预览.ps1 -Rebuild` 重新编译。只复制文档代码框内的命令，不复制反引号。

- 手机：默认底部书架、发现、下载、插件、设置；阅读足迹可从书架进入，也可以在设置中加入底栏。桌面使用左侧导航。
- 拖动书脊浏览，放手吸附；点中间书或“翻开这本漫画”打开详情。右上切换封面网格。书架显示自己的真实收藏。
- 发现页有每日推荐、原站榜单、更新、分类、书单。输入名称或作者，按回车搜索。每日精选从当前目录中选取 12 部；同一天、同一目录与换组次数下保持一致。栏目点击“查看全部”展开完整列表；源站提供更多链接时可继续分页。离线时仍能浏览已缓存目录。
- 分类从动漫屋读取题材，选择排序和连载状态后点“加载更多”。错误时显示原因或已有缓存，不伪造结果。

书架只显示真实收藏，空书架会提供发现漫画入口。旧版本的演示开关不会改变个人收藏。

## 收藏和整理

详情页点击收藏。书架标题旁的整理按钮可搜索、拖动、排序、批量选中和移组/移除。每本漫画可设置分组、标签、阅读状态和系列名。相同系列可切到套装视图；分组也作为发现页中的个人主题书单。

发现 → 更新 → 检查按钮会分批检查收藏。首次建立基线，以后的新章节会保留提示，打开详情或手动标为已读后清除提示。可切换未读、全部收藏及检查失败视图，批量标为已读或只重试检查失败的作品；检查失败会保留之前的未读提示。

## 阅读

详情页选择章节，或从足迹继续。阅读器上方打开章节/书签面板和设置。

- 分页、纵向分页、连续长条三种模式；宽屏下可开启双页，封面独立显示。
- 左右分区点击翻页，中间显示控制栏；键盘方向键翻页，空格切换控制栏，Esc 返回。
- 连续模式保存具体图片与图片内位置，可设置自动滚动。长按图片查看大图；分页可双指缩放。
- 阅读设置按漫画保存：方向、纸页效果、裁边、亮度、暖色、背景等。Android 接有音量键翻页与常亮接口；需在设备上确认实际效果。
- 拖动进度条时预览目标页码，松手后再翻到该页；键盘或无障碍调整直接跳转。章节目录打开时定位当前章节，可搜索章节名，并用定位按钮返回当前章。
- 书签按钮可写备注，也可收藏这一页。足迹页切换“书签与笔记”，可筛选页面收藏、搜索和删除。

章节末尾的“本章读完”打开结束面板，可标为已读并继续、只进入下一章或留在本页。切章后的提示提供“返回上一章”，回到刚才的页面及图片内位置。接近章末时只预备下一章首屏，不提前改变阅读记录；可在“设置 → 阅读习惯”关闭此功能，图片预载设为零时也不预备。

“阅读设置”中的单手操作支持左手、右手和跟随阅读方向；左右点击区域可分别调整，中间至少留出 20% 呼出工具栏。开启“工具栏集中在底部”后，返回、目录、书签、设置和翻页控制集中在底部，收起工具栏不改变漫画画面尺寸。

目录可单独切换章节的已读标记。书架显示已读章数；默认隐藏归档漫画，可通过“归档”筛选访问。书架的“继续阅读置顶”可关闭。“设置 → 阅读习惯 → 读完自动归档”默认关闭，开启后已知目录全部标为已读才自动归档；重新读取目录发现未读新章节时恢复到书架。手动归档保留收藏、阅读位置和离线文件。

在线图片地址过期时会尝试重新读取章节地址，核对页数和页面顺序后保留原位置；每次自动恢复只尝试一次，失败可手动重试。若原站调整了页数或顺序，会保留当前画面并提示从本章开头重新加载，避免把新旧页码错误对应。

## 本地漫画和下载

右上下载图标打开管理页，菜单选择 ZIP/CBZ/PDF、多选图片，原生端还可选图片文件夹。图片按自然数字顺序排序（1、2、10），ZIP 内目录不会写入任意系统路径。PDF 逐页转为本地图片；未接入 CBR。

详情选择下载章节后加入队列。暂停会在当前图片结束后停止，继续/重试保留完成页。可把一个任务移到队首，管理菜单也可暂停全部下载或重试全部失败任务。默认两章并发，可在设置改为一至四章。完成后优先从本机读取，封面尽量一起缓存。单张图超过 20 MB、单个压缩包/PDF 超过 256 MB 会拒绝导入或下载。

管理页显示离线容量，章节可删除或导出 CBZ。设置中的临时缓存清理会先确认影响，用于内存解码图和浏览器预览服务的网络图片；收藏、阅读位置和离线漫画保留。离线漫画用管理页清理。

从下载页进入“离线空间”，可查看每本漫画和各章节占用，设置下载容量上限（默认不限）。接近 90% 时显示提醒；下载即将超出上限时暂停，已完成图片保留。清理或调高上限后，回下载页继续任务。

点入单本漫画后，可按已读／未读筛选并多选完成的章节。清理前会展示章节明细和可释放大小，取消不会删除；确认后只删除选中离线文件，保留收藏、书签与进度。空间首页也可一次清理已读章节；正在写入的任务需先暂停，避免一边下载一边清理。

## 备份和恢复

设置 → 备份与同步：

1. JSON 资料备份：收藏、阅读进度、分组、书签、笔记和来源配置，不含正文图片或 WebDAV 密码。
2. 完整离线书库 ZIP：包含完成下载/导入的图片、资料和 SHA-256 校验清单，上限 512 MB。可自行放到网盘。更大的书库按章节导出 CBZ。
3. 恢复时先校验图片。资料以路径去重，保留较新阅读记录；删除标记避免旧备份重新带回已删收藏和书签。

## WebDAV

先在自己的服务端创建专用目录，填写完整 JSON 文件地址，例如 `https://dav.example.com/Manxia/library.json`。首次文件不存在时条件创建；已有文件用强 ETag 合并后条件上传，冲突会要求再同步。服务不支持强 ETag 时拒绝覆盖。

同步收藏、阅读位置、分组、笔记和书签。可选“上传离线书库到 WebDAV”或“从 WebDAV 恢复离线书库”，在同目录的 .offline.zip 中传输图片快照。上传也使用 ETag 条件写入，恢复先校验再合并；其他设备有独有章节时先恢复，再上传合并后的快照。不在后台自动上传漫画。原生端密码进入系统安全存储，浏览器仅保留在当前会话。未配置实际账号时无法证明真实网盘兼容性。

## 自定义源

设置添加 JSON 配置，指定 HTTPS 站点和 CSS 选择器。支持静态 HTML 的首页、搜索、详情章节和图片链接，不执行远程脚本。配置例子和字段解释见 `docs/SOURCES.md`。默认动漫屋适配器另有图片列表解码。

漫画源设置和搜索页可隐藏已确认不可读的在线作品。只依据原站明确的版权移除提示或 404/410 失效响应记录，按来源保留 24 小时；连接超时、验证与解析失败不会推断为没有版权。记录不进入备份与同步，收藏和已下载章节仍可访问；成功重新读取在线目录后清除该状态。

## 外观和语言

在“设置 → 外观与动效”选择背景图片。漫匣将图片缩小为最长边 1920 像素的静态背景并保存在本机，支持 20 MB 以内的可解码图片。开启“跟随背景配色”后，导航、按钮、阅读工具栏与主题底色随图片调整。关闭后使用当前主题的配色（默认蓝色）；可以调整背景遮罩和柔化，或恢复默认背景。

阅读工具栏、目录及设置使用应用主题。在“阅读习惯 → 阅读默认背景”选择“跟随应用”，阅读画面四周也会使用当前背景；单本漫画的“阅读设置 → 阅读背景”优先。此前指定过夜墨、纸白或旧纸的漫画保留原选择。

背景图片文件不包含在 JSON 或离线漫画 ZIP 备份中，换机后需要重新选择图片；外观参数可保留，找不到本地图片时回退到默认底色。

设置有夜间模式、动画、指针/设备倾斜、材质档位、封面取色、预载、触感、大字号、高对比度及中英/繁体主要界面翻译。网站漫画名、介绍和部分动态提示保留原文。设备倾斜和玻璃折射依赖硬件/渲染器，不以浏览器预览代替真机验收。

## 设置与版本更新

设置首页按功能提供六个入口：外观与动效、阅读习惯、漫画源、下载与缓存、备份与同步、关于与更新。语言、文字大小和高对比度位于“外观与动效 → 语言与可读性”。底部入口与排序仍在外观页面中调整。

从发现页的搜索栏或顶部搜索按钮进入独立搜索页，可切换漫画名称／作者、重用或清空最近搜索；网络请求期间保留上次结果，返回发现页保留此前分类。

“漫画源 → 检查当前源”依次检查列表、目录和章节图片地址，可取消并查看抽查详情。无版权作品会明确提示并继续抽查其他作品；地址检查成功不代表图片已在你的设备上显示。

“关于与更新 → 检查 GitHub 更新”显示本机与最新正式版的比较结果。Android 新版本可应用内下载并校验，然后点击“安装更新”，按系统提示覆盖安装，保留书库。第一次可能要在系统设置中允许漫匣安装应用，再返回点击安装。旧版首次升级到带此功能的版本，直接从发行页下载 APK 覆盖安装即可。
