# 动效与操作衔接 · 0.3.0

本版围绕“按下有反馈，动作能衔接，中断后继续操作”整理统一动效语言。立体书和悬浮毛玻璃导航保持原有视觉方向。

## 节奏

参数集中在 `lib/ui/room_motion.dart`：按压 110 ms，控件反馈 180 ms，页面 260 ms，书架首次入场 420 ms，开书 760 ms、返回 580 ms，收藏飞入 440 ms。开书先抽出书体，再沿书脊翻开封面和交错书页，详情保持展开状态；空间移动和翻页使用同一进度的不同区间。导航的头部与尾滴分别使用弹簧，拉开后由连续轮廓桥接，反向操作承接两者当前运动状态。

时长是设计参数，不等于设备实际帧率或每次输入的端到端耗时。

## 完整流程

- **拖动与选书**：直接跟手移动，松手后回正并吸附。连续按箭头累积目标，不因动画尚未结束而吞掉下一次操作。指针视差平滑跟随，离开后回到中立位置。
- **开书与返回**：使用同一本书在实际书架与详情之间移动；封面转过正面后绘制内页，交错翻动书页，落位保持打开。返回沿原路径合上归位。快速重复点击不会叠加路由，途中返回会收回。
- **快速切页**：捕获所有仍可见页面的位置和透明度，再从这些状态转向新目标，不把过渡重新从零播放。已访问页面保留滚动与选书状态，非当前页面停止自身动画；仅当前页面参与点击与辅助语义。
- **玻璃导航**：底板固定，液滴用独立绘制层连接头部和滞后的尾部，合并后吸附回弹。拖动时预览，释放后切页，取消则回到原选项；液滴、图标和页面共同响应选择。
- **页面手势**：页面直接跟随水平拖动；距离或速度足够时提交切换，否则回位。系统取消指针时不提交，书架自身的拖动和页面中的横向控件优先处理各自手势。
- **收藏**：飞入从实际书籍位置开始，朝书架入口收束。高屏手机仍落到下方导航，取消收藏会撤回未完成的飞入。
- **进入阅读**：详情、下载和书库等普通页面共用短滑移与淡入。阅读工具栏在正文上方滑入滑出，切换时不挤压漫画，不改变阅读视口和进度。
- **资料加载**：宽屏详情的封面固定在行首，作者、题材和简介到达后不改变书籍落点。

## 减少动效

系统减少动态效果或关闭应用动效时，取消自动入场、弹簧、飞入和页面过渡；导航和阅读工具栏直接呈现目标状态。手动拖动仍可操作。玻璃画质与动效开关分开设置。

## 验证

自动测试覆盖快速切页的画面连续性、选书连点、开书途中返回、收藏撤回、封面落点和正文视口不变，以及原有的底栏拖动／取消、安全区、减少动效和详情只初始化一次。

浏览器真实录屏保存在本机 `artifacts/motion-book-open.gif`、`motion-book-return.gif` 与 `motion-navigation.gif`。这些录屏用于检查衔接，不能代替 Android 真机触感、实际帧率、功耗或不同 GPU 的玻璃效果验收。
