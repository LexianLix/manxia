# 0.2.1 玻璃与动效调整

本轮根据反馈重做了底部导航与几处主要过渡。对照原项目的公开界面和交互结构独立实现；没有将相似截图当作动效已还原的证明。

- 底栏改为悬浮毛玻璃胶囊，采用实际背景模糊、较薄的奶白染色、高光边缘和柔和投影。正文延伸到底栏后方，封面颜色与滚动内容会被玻璃采样。
- 选中块使用弹簧移动；拖动时先预览目的地，松手才切页。按压有轻微形变，指针取消则回到原位置。
- 页面切换共用方向滑移、淡入与短暂失焦；结束时保留页面状态，避免重新初始化和重复加载。
- 立体书架新增从中间向两侧展开的入场，拖动时书体倾斜，松手后回正并吸附；标题随选书切换。
- 从书架打开详情时，书从点击位置移向前景，再展开封面，背景逐渐失焦；返回时反向收回。
- 玻璃有低画质回退；高对比度模式提高底色不透明度。系统减弱动态效果或关闭应用动效时取消入场、弹簧与页面过渡。

自动检查包含底栏拖动期间不切页、释放提交、取消恢复、减弱动态效果和底部安全区，以及开书前后详情只初始化一次。还需在 Android 真机上确认触感、折射和帧率；浏览器毛玻璃效果与原生渲染后端可能不同。
