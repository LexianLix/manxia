# 发现与路由动效批次

日期：2026-10-23；于2026-10-24随v0.3.3发布。本记录保留当时的源码与本地验证；对应安装包及原生启动检查见 `QA-0.3.3.md`。

## 已实现

- `RetainedSections` 仅建立访问过的栏目，保留分类筛选和来源目录；高度按当前权重接续变化。260ms 时钟采用统一曲线，快速改点先采样当前姿态，返回沿实际状态接续。
- 两个文字密集栏目使用先淡出、后显现的共享纸面，避免榜单、网格和主推同时叠字。隐藏层排除触摸、焦点和语义，停止 ticker；重绘边界隔离静态内容，不逐帧重建漫画网格。尚无 Android 真机性能数据。
- 发现五栏目、四类榜单和发现/搜索视图使用同一机制。搜索建议、历史与返回入口采用短交接；文字框保持原位，不因输入重播整页进场。
- 新搜索保留旧结果，加载时降低其可见度并禁止误点。记忆搜索词后再次检查请求世代；来源参数固定为提交时的词和搜索方式。新结果与失败、重试有独立状态，失败不清空既有结果。
- 分类加载条、错误面板及分页按钮连续收放。已有漫画保留；此处未完成分页新条目的统一入场，也未重写虚拟网格。
- 普通 `MaterialPageRoute` 协调主动画和 secondaryAnimation：纸面先遮住离场文字，再显现新页面；底层小幅退让，返回逆向播放。物理书共享飞行使用原有独立过渡。
- 开源许可页读取 PackageInfo 版本；元数据不可用时仍允许打开许可证。

## 验证范围

- 新增状态回归覆盖快速三向重定向、连续高度、已访问栏目只挂载一次、返回筛选保持、搜索加载期间保留结果、过时响应丢弃、错误重试及系统/应用减少动效。
- 路由回归覆盖前后景位移、进入50ms后返回不重置姿态、完整双向过渡及减少动效立即定位。
- Flutter 测试帧录制位于忽略目录 `.qa/discovery-motion-final3/` 和 `.qa/route-motion/`。包含栏目/榜单中间态、分类等待、搜索等待/结果/失败和路由往返。记录来自真实 Flutter 组件、隔离测试资料与受控异步来源；图像请求在测试中不联网，不作为真实漫画网络或设备帧率验收。
