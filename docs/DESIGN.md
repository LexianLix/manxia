# 漫匣 · 视觉与交互

面向喜欢实体漫画单行本的读者。界面的主要任务是选书、续读和追更。

主视觉继承 Wenku8_Flutter 的纸质书脊与奶白材质意象，代码独立实现。将视觉张力集中在可抽出的实体漫画书，周围界面保持安静。

色彩：纸白 #F7F7F2、墨黑 #262C29、灰绿 #7B867C、书签绿 #47775E、浅绿 #E6ECE5、夜墨 #171D1A。

字体：思源宋体用于标题与书脊；系统无衬线用于操作与说明。小型英文字段使用系统等宽字体。

布局：宽屏侧边导航 + 书架主区 + 底部阅读入口；手机底部导航，书架保持中心舞台。页面宽度上限 1440，核心书架最大宽 960。

签名交互：窄书脊陈列 → 选中漫画升起并展开封面 → 连续过渡至详情 → 沉浸阅读。可关闭动效，可切换平面封面视图。减少动画偏好优先于应用动画开关。

创新顺序：实体书签（真实阅读记录）、封面到详情转场、立体/平面书架切换。追更仅展示来源真实返回的章节状态，不伪造更新数量。

首次启动展示演示收藏，并在书架标识；用户第一次收藏后进入真实个人书架。演示目录是公开缩略图地址快照，不含漫画正文、预设阅读进度或账户数据。

发现/搜索/详情/正文使用动漫屋真实请求；加载失败明确提示并可重试或打开原站。浏览器预览网关仅解决开发跨域，Android 直接读取来源。
