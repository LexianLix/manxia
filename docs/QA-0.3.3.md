日期：2026-10-24。目标版本0.3.3+12；安装包尚在准备，不能把下列本地验证写成已发布或真机通过。

## 两项用户反馈

- 封面向内缩进：先增加真实 CoverHinge 组件的透视断言，确认外侧边缘远离读者，w=1.207474（应小于1）。修正封面和纸页的旋转方向，平面入口展开到书脊外侧，反面绘制纸面；原始封面留在固定详情落点。立体书采用同一方向并增大展开幅度。逆向返回和系统减少动效保留。
- 《火影忍者》诊断只有一次 mobile、29250字符、0分组/0章节和“外部搜索”错误。新增请求链回归确认此状态会直接中止，未检查桌面版。现在将“当前入口只有外部搜索”与“原站明确移除/迁移”分开，前者读取同路径的公开桌面版，后者保留原提示。不会跟随外部搜索网址或挪用推荐作品的章节。

## 来源可用性边界

- 本次实际直连手机与桌面页均HTTP200，但都返回版权方要求移除链接的 `.warning-bar`，没有自身章节容器。采集到手机页16706字符、桌面页62742字符；同桌面请求通过本机现有代理另得61918字符，仍为同类提示。正文仅保存在忽略目录，诊断不含Cookie、登录信息或个人书库。
- 这与用户29250字符的“外部搜索”响应不同，不能声称拿到了用户当时完整网页，也不能保证该作品在其手机上恢复阅读。不同时间、入口与网络返回需分别判断。
- 之前捕获的真实桌面目录有553章；新回归以用户报告的搜索入口状态接续该历史响应，确认可以恢复553章。该结果证明回退链与解析，不代表今天直连可读。公开网页索引或历史录制同样不作为当前在线成功依据。
- 若桌面版也未提供目录，界面如实显示原因，提供重试、复制诊断和换源查找；不会把空目录包装为成功。

## 换源流程

- 仅从已保存的声明式源及已启用插件源选择，不自动添加第三方网站。查询固定来源和漫画名，不修改默认发现源。
- 切源期间保留原结果，拒绝较早请求回填；网络失败可重试。来源停用/移除后不展示其结果为当前可打开项。
- 用户确认结果后打开独立版本详情，沿用与书架相同的开合路由；原书收藏、分组及阅读位置不被替换，不自动把旧页码映射到另一版本。
- 没有其他来源时进入聚焦的漫画源设置，支持添加已有静态HTML源。当前API1仍为声明式配置；本版本没有实现可执行插件生态。
