# v0.3.5 验证记录

版本0.3.5+14，纳入 [连续性批次](QA-0.3.4.md) 的开书、封面、版权、滚动、翻页和分页，以及 [目录/跨章交接](QA-MOTION-READER.md)。v0.3.4候选在发行前被拦下，未提供APK。

## 双指与翻页接续

- 原候选依靠下一帧重建来暂停PageView手势。无间隔地发送第二指落下和移动事件后，期望缩放大于1.2，实际仍为1.0，回归确实失败。
- 现在由InteractiveViewer统一识别手势：未缩放时的一指位移交给真实ScrollPosition的drag/hold/ballistic流程，双指由同一识别器缩放，放大后拖图保持页码。没有在指针事件里更换框架内部识别器，也没有额外手动模拟惯性。
- 匹配原滚动触摸阈值，子内容的点击和长按仍沿用系统阈值。快速连点、改向、中断、减少动效和原生图片首屏交接保持既有回归。
- 新增无帧间隔/有帧间隔双指起手、横向/RTL/纵向短促甩页释放速度，以及拖动/缩放中关闭时释放活动的检查。
- 指针拖动通过公开scrollBehavior配置交由统一识别器，PageView保留原来的滚动物理、滚轮和语义动作。补查跨阅读方向的甩动不会误翻页，手指按下能接住正在移动的页面。滑动速度按阅读轴投影并遵守原物理阈值。

## 证据边界

- 组件画面仍使用隔离数据和缓存；版权提示来自实际公开响应回放，阅读使用真正解码的分镜色块。它们证明限定交互与渲染，不代表动漫屋当前全部作品可读。
- v0.3.4开书动图可继续复现该版本同一开书实现，最后落在真实版权提示和原站作品封面。后续手势画面另存 `.qa/reader-gestures-v035/`。
- 全流程动效仍需继续核对阅读模式切换、各类弹层、控件反馈、导航成员变化与宽屏收藏落点。物理iQOO/ARM64完整阅读、帧率、功耗及发热尚未验收。
