## 概要

Manxia は、作品探し・自分だけの本棚・ローカルインポート・オフライン読書をひとつにまとめた Android スマートフォン／タブレット向け漫画リーダーです。クリーム色と深緑を基調に、立体感のある本棚、背表紙の色を表紙から抽出する装丁、背を軸に開く表紙アニメーション、フローティングのすりガラス風ナビゲーションバーなど、実物の本の手触りを大切に設計しています。

デフォルトのソースとして动漫屋（Dongmanwu）を接続し、毎日のおすすめ、全カテゴリのブラウズ、絞り込み検索、オリジナルランキングを利用できます。手持ちの画像・CBZ・PDF をインポートして持ち運べるライブラリに整理することも可能です。コレクション、読書進捗、ダウンロードしたコンテンツは端末内に保存され、手動バックアップや WebDAV 同期にも対応します。

## 特長

- **3D 本棚** — 表紙は実物の本のように全面装丁され、背表紙の色は各表紙のアートから抽出。本をタップすると背を軸に表紙とページが開き、戻ると本が棚に収まります。慣性スクロールとスプリングスナップ、密度調整、リスト表示に対応。
- **すりガラスの UI** — 水滴のようなトランジションとジェスチャーナビゲーションを備えたフローティングバー。モーション軽減やマテリアル品質の設定も変更できます。
- **プラグイン「閲覧室」** — インストール、有効／無効、更新、設定、アンインストールができるプラグインストア。テーマ、読書プリセット、漫画ソース、ナビゲーションレイアウトを自由に組み合わせ可能。ローカルのプラグインファイルやカスタムのオンラインリポジトリにも対応。
- **パーソナライズされたホーム** — 本棚・発見・ダウンロード・プラグイン・設定の 5 セクションに加え、読書履歴ショートカット、タブの並べ替え、起動ページの設定が可能。本ごとに画面常時オン、見開きデフォルト、背景、ツールバーの自動非表示なども設定できます。
- **作品探し** — 毎日のおすすめ、人気／新着／コレクション数ランキング、カテゴリ・連載状況・並び替えの絞り込みとページング、タイトル・作者検索、検索履歴、連載作品のフォロー。
- **没入感のある読書体験** — 縦連続スクロール、横／縦ページめくり、左→右／右→左の読み方向、ワイド画面での見開き表示。カーブするページめくり効果、ピンチズーム、余白の自動トリミング、自動スクロール、画像内位置の復元、本ごとの設定に対応。
- **読書ツール** — 話リスト、複数ブックマーク、メモ、ページのお気に入り、画像の先読み、明るさ・色温度・背景の調整。
- **ライブラリ管理** — カスタムグループ、タグ、読書ステータス、並び替え、ドラッグ＆ドロップ、一括操作。読書履歴は日付で閲覧・検索できます。
- **オフライン＆インポート** — 同時実行数制御、一時停止／再開、リトライ、キャッシュ統計、CBZ エクスポートを備えたダウンロードキュー。画像、フォルダ、ZIP／CBZ アーカイブ、PDF のインポートに対応。
- **バックアップ＆同期** — JSON データバックアップと、オフライン画像と SHA-256 マニフェストを含むライブラリ全体の ZIP バックアップ。WebDAV はメタデータのマージとライブラリ全体の転送に対応。
- **ソース＆設定** — 静的 HTML の漫画ソースを設定可能で、ソースのヘルスチェック付き。カタログが利用できなくなった場合は、コレクションと読書位置を保持したまま、設定済みの他のソースを検索できます。大きな文字と、簡体字中国語・繁体字中国語・英語の UI に対応。

本棚には自分のコレクションだけが表示されます。初回起動時は「発見」ページから作品を追加してください。ランキングはソースサイト本来の順序に従い、毎日のおすすめはカタログから選ばれます（人気数値の捏造はしません）。

## プラグインと自作

Manxia には「Warm Paper Study」「Blue Hour」「Japanese Reading Habits」「Long Webtoon Scroll」「Local Collection Room」などの組み込みプラグインが含まれます。自作も可能です。プラグインは JSON マニフェストで定義され、テーマ、読書パラメータ、静的 HTML の漫画ソース、ナビゲーションレイアウトを扱えます。アプリの再コンパイルは不要です。

Plugin API 1、マニフェスト形式、完全なテンプレートについてはプラグイン開発ガイドを参照してください。サンプルは `plugins/` ディレクトリにあります。開発者ツールにはマニフェスト検証とカタログ生成があり、オンラインプラグインのインストールは SHA-256 で検証されます。個人のライブラリと本ごとの設定は常に分離して保持されます。

## ダウンロードとインストール

対応環境：**Android 7.0 以降**。リリース APK はプロジェクト固定のリリースキーで署名され、アーキテクチャ別に分かれています。

| デバイス | パッケージ |
| --- | --- |
| ほとんどの Android スマートフォン／タブレット（推奨） | ARM64 · arm64-v8a |
| 古い 32 ビット ARM デバイス | ARMv7 · armeabi-v7a |
| x86_64 デバイスまたはエミュレータ | x86_64 |
| 整合性チェック用 | SHA256SUMS.txt |

[GitHub Releases](https://github.com/LexianLix/manxia/releases) からお使いのデバイス向け APK をダウンロードしてインストールしてください。アプリ内の「更新を確認」は最新の GitHub リリースを照会し、ダウンロードリンクを提示します。最新のバージョン番号は Releases ページでご確認ください。

## ソースからビルド

ツールチェーン：**Flutter 3.47.7 / Dart 3.13.5**。Android ビルドには **JDK 17 と Android SDK** が必要です。

```bash
git clone https://github.com/LexianLix/manxia.git
cd manxia
flutter pub get
flutter build apk --release --split-per-abi
```

Android 向けにビルドする前に、`flutter doctor` で Android セットアップを完了させてください。自前ビルドのパッケージは自分のキーで署名され、公式リリースビルドを上書き更新できません。キーやパスワードをリポジトリに入れないでください。

チェック：

```bash
flutter analyze --no-pub
flutter test --timeout 30s
```
